Babelo для Chrome / Edge — непрерывный перевод видео онлайн с озвучкой.

Установка (один раз):
1. Распакуйте архив в постоянную папку (не удаляйте её потом).
2. Откройте chrome://extensions (в Edge — edge://extensions).
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение», выберите эту папку.

Использование: откройте видео (YouTube и другие сайты, где у видео есть субтитры), нажмите F10.
F10 ещё раз — меню, F10 дважды подряд или Esc — выключить. Клавиши работают, когда активна страница с видео.
Лучший перевод и подсказки слов — когда на этом же компьютере запущена программа Babelo с готовыми моделями.
